# Youna

**Youna — AI Therapist, Wellness Coach & Companion Platform**

Youna is an AI-native platform that serves as your personal emotional wellness companion, combining:

- **AI Chat Companion** — conversations that genuinely learn your personality
- **Personality DNA Engine** — Big Five, MBTI, DISC, Attachment Theory, Enneagram
- **Emotional Intelligence** — empathy modeling, sentiment analysis, reflective conversations
- **Mood Tracking** — daily mood checks with pattern analysis
- **Journaling** — free-form and AI-guided reflection
- **Daily Check-ins** — consistent presence and support
- **Clinical Safety First** — crisis detection, professional referral, clear boundaries

## Routes

- **/** — Landing page
- **/chat** — Chat interface with Youna
- **/assessment** — Personality assessment onboarding
- **/features** — Feature overview
- **/about** — About Youna and our mission

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (icons)

## Phase One MVP

From the PRD, Phase One includes:

1. User Onboarding with personality assessment
2. AI Chat Companion with mock responses
3. Personality DNA Engine (Big Five, MBTI, DISC, Attachment Theory, Enneagram)
4. Conversational Memory (session-based)
5. Mood Tracking
6. Journaling (AI-guided prompts)
7. Daily Check-ins
8. Goal & Habit Tracking
9. Safety Layer (crisis detection, disclaimers)
